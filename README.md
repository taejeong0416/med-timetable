# 의대 시간표 (PWA)

학교에서 받은 시간표 엑셀(.xlsx)을 올리면 주간 시간표와 시험 D-day를 만들어 주는 웹앱.
서버 없이 브라우저 안에서만 동작한다. 올린 파일은 기기 밖으로 나가지 않는다.

## 구조

| 파일 | 역할 |
|---|---|
| `parser.js` | 엑셀 → 일정 배열. `"N주"` 앵커로 블록 그리드를 자동 탐지 |
| `app.js` | 화면 렌더, localStorage 저장 |
| `preset.json` | 기본 탑재 시간표. 지우면 첫 화면이 업로드로 바뀜 |
| `sw.js` | 오프라인 캐시 |

## 로컬에서 보기

```
npx serve .
```

## 배포 (택1)

```
npx vercel --prod          # Vercel
npx netlify deploy --prod  # Netlify
```

정적 파일이라 빌드 과정이 없다. 폴더째 올리면 끝.
서비스워커와 홈 화면 추가는 HTTPS에서만 동작하므로 로컬 IP(http)로는 PWA 설치가 안 된다.

## 다른 학교 엑셀도 받으려면

`parser.js` 상단 상수만 손보면 된다.

- `RE_WEEK` / `RE_PERIOD` — 주차·교시 라벨 형식
- `ALIAS` — 약어를 정식 과정명으로 (`인구1` → `인체구조I`)
- `GUESS` — 과정 태그가 없는 셀을 제목으로 추론
- `KINDS` — 시험·실습 등 유형 키워드
